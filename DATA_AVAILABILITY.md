# Data Availability

Large Sentinel raw products are not committed to this GitHub repository because they exceed normal GitHub file-size limits.

Required raw products used in the current experiment:

```text
Sentinel-1A GRD:
S1A_IW_GRDH_1SDV_20250805T110854_20250805T110919_060400_0781F8_677D.zip

Sentinel-2C L2A:
S2C_MSIL2A_20250803T033601_N0511_R061_T48RVU_20250803T085013.SAFE.zip
```

Place them locally as:

```text
data/raw/sentinel1/
data/raw/sentinel2/
```

Small processed AOI rasters, scripts, logs, and result summaries are included.
